# 작가노트 매니저

실리태번의 기존 **작가노트 창** 안에서 작가노트와 기본 작가노트를 여러 항목으로 관리하는 확장입니다.

## 사용 방법

1. 확장을 설치한 뒤 실리태번 화면을 새로고침합니다.
2. 평소 사용하던 **작가노트** 창을 엽니다.
3. 기존 작가노트와 기본 작가노트가 각각 첫 항목으로 표시됩니다. 내용을 다시 옮겨 적을 필요가 없습니다.
4. 각 영역의 **항목 추가**를 누르면 기존 첫 항목 아래에 새 항목이 이어집니다. 별도의 추가 항목 제목이나 설명 없이 같은 목록에서 관리하며, 이름, 본문, 켜기/끄기, 월드인포 스캔 포함 여부, 삽입 위치·깊이·역할은 항목마다 따로 설정할 수 있습니다.
5. 제목 오른쪽의 화살표를 누르면 항목을 접거나 펼칩니다. 접혀 있어도 맨 왼쪽의 사용 토글과 제목 입력칸은 계속 보입니다. 제목 수정이나 토글 조작은 항목을 접거나 펼치지 않습니다.

기존 첫 항목과 새로 추가한 항목 모두 제목을 적고 개별적으로 접을 수 있습니다. 접힘 상태는 저장되어 채팅을 다시 열어도 유지됩니다. 접기는 표시 방식만 바꾸며 주입 여부나 깊이에는 영향을 주지 않습니다.

입력칸, 버튼, 접기 아이콘과 구분선에는 실리태번의 기본 스타일을 사용합니다. 제목칸 바깥 왼쪽에 슬라이드 토글, 바깥 오른쪽에 접기 화살표를 배치합니다. 제목칸과 본문칸의 좌우 선은 같은 위치로 정렬합니다. 본문은 기본 작가노트와 같은 8줄 높이로 시작합니다. 별도의 카드 배경색이나 고정 강조색을 지정하지 않으며 토글을 포함해 현재 실리태번 테마를 따릅니다.

| 영역 | 적용 범위 |
| --- | --- |
| 작가노트의 추가 항목 | 현재 채팅에 저장됩니다. 다른 채팅에 자동으로 추가되지 않습니다. |
| 기본 작가노트의 추가 항목 | 새 채팅에 처음 한 번 복사할 원본입니다. 수정해도 이미 만들어진 채팅은 바뀌지 않습니다. |

토글을 꺼도 본문은 유지됩니다. 다시 켜면 같은 본문과 깊이를 사용합니다. 삭제는 확인창에서 승인한 항목에만 적용됩니다. 추가 항목은 켜져 있고 본문이 있을 때 매번 전달합니다. 깊이 0은 마지막 메시지 위치이며, 숫자가 커질수록 앞쪽에 배치됩니다.

## 항목별 주입 설정

- **월드인포를 스캔 대상에 포함**: 이 항목의 본문을 월드인포 키워드 검색에 사용할지 결정합니다. 체크를 꺼도 항목 자체의 주입은 유지됩니다.
- **삽입 위치**: 메인 프롬프트 전, 메인 프롬프트 이후, 채팅 내 삽입 중 선택합니다.
- **깊이·역할**: 채팅 내 삽입을 선택했을 때 적용합니다. 다른 위치에서는 비활성화되며 값은 보관합니다.
- 추가 항목의 설정은 서로 독립적입니다. 기존 첫 작가노트의 스캔 설정을 변경해도 추가 항목의 설정은 바뀌지 않습니다.
- 새 항목은 채팅 내 깊이 4, 시스템 역할, 스캔 포함 해제로 시작합니다. 이전 버전 항목은 기존 깊이·시스템 역할·스캔 동작을 유지하도록 처음 읽을 때 이전 스캔 설정을 저장합니다.

## 기존 작가노트와의 연동

첫 항목의 본문·깊이·위치·역할·빈도는 실리태번의 원래 입력칸과 저장값을 그대로 사용합니다. 기존 명령으로 본문을 수정해도 반영됩니다. 첫 항목의 토글은 기존 주입 빈도를 0으로 설정하여 끄고, 다시 켜면 꺼지기 전 빈도를 복구합니다.

기본 작가노트는 실리태번과 같은 **처음 복사 후 독립** 방식입니다.

- 첫 항목의 초기 본문·위치·깊이·역할·빈도는 실리태번 기본 처리를 그대로 따릅니다. 확장이 기존 값을 덮어쓰거나 빈 본문을 다시 채우지 않습니다.
- 실리태번의 새 채팅 생성 이벤트(`CHAT_CREATED` / `GROUP_CHAT_CREATED`)가 발생할 때, 기본 작가노트의 추가 항목을 해당 채팅에 한 번만 복사합니다. 제목·본문·토글·접힘·위치·깊이·역할·스캔 설정이 함께 복사됩니다.
- 복사한 뒤에는 서로 독립적입니다. 채팅에서 수정·삭제·켜기/끄기를 해도 기본 원본이나 다른 채팅은 바뀌지 않습니다. 기본 원본을 고쳐도 이미 초기화된 채팅은 바뀌지 않고, 이후 새로 시작하는 채팅에만 적용됩니다.
- 기본 목록이 비어 있을 때 시작한 채팅도 이후에 자동으로 채워 넣지 않습니다. 채팅에서 삭제한 항목도 다시 열거나 새로고침한다고 복구하지 않습니다.
- 브랜치·채팅 복사로 이미 항목 메타데이터를 이어받았다면 그대로 사용하며, 현재 기본값을 다시 복사하지 않습니다. 기존 대화가 있고 확장 메타데이터가 없는 채팅에도 기본 항목을 소급해서 넣지 않습니다.
- 추가 항목은 **현재 채팅에 저장된 항목만** 주입합니다. 기본 작가노트 원본을 공통 경로로 추가 주입하지 않습니다. 기존 첫 작가노트의 빈도·캐릭터 작가노트 동작은 실리태번이 처리하며 추가 항목의 개별 토글은 그대로 유지합니다.

### v0.1.8 이전 버전에서 업데이트

이전 버전의 지속 연결·공통 주입은 제거했습니다. 업데이트를 처음 실행할 때 기존 공통 추가 항목의 내용을 보관하고, 이전 버전 메타데이터가 있는 채팅은 그 보관본을 한 번만 복사하여 독립시킵니다. 나중에 여는 이전 채팅도 이후에 수정한 기본값이 아니라 업데이트 시 보관본을 사용합니다. 기존 채팅의 첫 본문·설정·채팅 전용 항목은 보존하며, 꺼진 항목도 삭제하지 않습니다. 이 변환 이후에는 어떤 수정도 다른 채팅에 전파되지 않습니다. 이전 버전에서 이미 덮어써진 내용을 과거 상태로 복구하는 기능은 아닙니다.

실리태번의 캐릭터 작가노트 설정도 그대로 유지됩니다. 캐릭터 작가노트가 첫 항목을 대체하도록 설정되어 있다면 첫 항목에는 그 기존 규칙이 적용됩니다. 추가 항목들은 독립적으로 적용됩니다.

## 설치

실리태번의 확장 설치에서 다음 저장소 주소를 입력합니다.

```text
https://github.com/foreverharibo-boop/author-note-manager
```

### 파일로 설치

압축을 풀어 다음 구조가 되도록 `author-note-manager` 폴더를 넣습니다.

```text
SillyTavern/public/scripts/extensions/third-party/author-note-manager/manifest.json
```

폴더 안에는 `index.js`, `model.js`, `style.css`도 함께 있어야 합니다. `author-note-manager/author-note-manager`처럼 폴더가 두 번 중첩되지 않도록 확인합니다. 설치 후 실리태번 화면을 새로고침합니다. 별도 API 키나 서버 플러그인은 필요하지 않습니다.

## 저장과 제거

새 채팅용 기본 항목은 실리태번 사용자 설정에, 각 채팅의 복사본과 직접 만든 항목은 해당 채팅 메타데이터에 저장됩니다. 체크포인트나 채팅 복사 시에는 실리태번의 메타데이터 복사 동작을 따릅니다.

확장을 비활성화하거나 제거한 뒤에는 새로고침합니다. 추가 항목은 주입되지 않으며, 기존 첫 작가노트는 마지막으로 저장된 내용과 설정으로 실리태번에서 계속 사용할 수 있습니다. 확장을 다시 설치하면 남아 있는 항목 데이터를 사용합니다.

## 검증 범위

`npm test`로 첫 복사와 이후 독립성, 기존 노트·빈 노트 보존, 중복·재복사 방지, 이전 버전의 일회성 변환, 항목별 삽입 위치·깊이·역할·월드인포 스캔과 토글, 채팅·브랜치 분리 및 그룹 채팅 동작을 검사할 수 있습니다.

개발 중 실리태번의 작가노트 주입 함수와 창 구조를 이용한 DOM 연동 검사도 수행했습니다. 실제 사용자 서버에서의 RP 생성 및 브라우저 화면 검수는 아직 수행하지 않았습니다. 첫 설치 후 실리태번의 프롬프트 확인 화면에서 원하는 깊이와 본문으로 전달되는지 확인할 수 있습니다.
